# SwasthyaSeva

Healthcare management platform with Turborepo monorepo architecture.

## Install

```bash
npm install
```

## Run

```bash
# All apps
npm run dev

# Individual apps
cd apps/admin && npm run dev    # Port 3001
cd apps/web && npm run dev      # Port 3000
cd apps/doctor && npm run dev   # Port 3002
cd apps/clinic && npm run dev   # Port 3003
cd backend && npm run dev       # Port 5000
```
